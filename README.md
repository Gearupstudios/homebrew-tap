# Gear Up Studios Homebrew Tap

This is the official Homebrew tap for Gear Up Studios applications.

## Installation

```bash
brew tap gearupstudios/tap
```

## Available Apps

### EyeRelief
A macOS app to prevent eye strain using the 20-20-20 rule.

```bash
brew install --cask eyerelief
```

## Updating

```bash
brew update
brew upgrade --cask eyerelief
```

## Uninstalling

```bash
brew uninstall --cask eyerelief
brew untap gearupstudios/tap
```
